# 《Cyber-X》项目背景与游戏创意摘要

## 一句话定位

赛博朋克版《神界原罪2》的环境涌现 × 《陷阵之志》的明牌位移博弈 × 《Cogmind》的模块化义体 × 回合制搜打撤：一款零剧情、只靠机制本身制造“绞尽脑汁破局”快感的战术游戏。

## 一、要解决的核心矛盾

- 《神界原罪2》《博德之门3》战斗极爽，但被百万字叙事包裹。
- 《陷阵之志》纯粹烧脑，却因数值克制、缺乏成长而“爽感不足”。
- **项目目标**：把前者的战斗精华抽离出来，用后者的棋盘清晰度重新封装，并让**“打赢”**和**“捞到好处”**变成两个互相拉扯的目标。

## 二、三大设计支柱

| 支柱 | 解决的问题 | 机制来源 | 市场验证 |
| :--- | :--- | :--- | :--- |
| **系统涌现** | 战斗解法单一、直播没看点 | DOS2 /《旷野之息》化学引擎式标签状态机 | 《Mewgenics》$51.7M（零剧情纯涌现） |
| **明牌 + 回溯** | 烧脑战棋的挫败感与“憋屈” | 《陷阵之志》意图预告 + 《Tactical Breach Wizards》回合内免费撤回 | 98% 好评 / $4.25M |
| **热插拔 + 搜打撤** | 线性关卡打完即弃、无长尾 | 《Cogmind》部件即血条 + 《Quasimorph》撤离带出 | 96% 与 82%（$11.9M） |

- **反面教材**：《Showgunners》题材和“砍叙事只留战斗”的方向全对（89% 好评），但只用传统掩体对射 + 一次性线性关卡，营收停在 $0.73M。

## 三、涌现引擎（技术核心）

不写“技能 A 遇到物品 B”的特判脚本，只维护一张**标签表**。所有实体（玩家、敌人、尸体、地上砍落的义体、抛弃的货舱、地形设施）共享同一套标签与同一套法则，使交互数量从“加法”变成“乘法”。

- **四类作用力**：导电、极寒、高热、动能
- **标签示例**：`金属导电`、`精密电路`、`易燃`、`实体阻挡(重量级)`、`脆弱玻璃`
- **关键设计**：让“化学状态”与“物理位移”双向交接，形成多米诺连锁：
  - 示例链路：打爆冷却管 -> 地面变冰 -> 任何推力变成 3 格直线滑行 -> 撞上窗户 -> 破窗坠落 -> 坠落毁掉目标身上的义体。

## 四、五个标志性高光瞬间（设计标尺）

1. **小数值地形杀**：15 点伤害的破拳头秒杀 300 血 Boss（冰面滑行 ×3 把他推出 80 楼）。
2. **保战利品的博弈**：推下楼会让橙装跟着摔没，于是把货舱扔在窗前垫刀，让 Boss 撞墙眩晕而非坠楼，再用高频刃 100% 无损斩下义体，当场焊到自己断掉的肩膀上。
3. **废件即棋盘道具**：地上的废铁机械臂扔在两滩积水之间的旱地上，直接变成一座导电桥。
4. **敌招为我所用**：黑入敌人的视觉义眼使其偏转 90°，让他自己把电磁炮轰进水里。
5. **战损逼出邪道流派**：拆光散热器装满货舱，靠“红温漏电”把惩罚机制玩成核心输出。

## 五、身体即 Build（Cogmind 精髓，5 槽压缩版）

| 槽位 | 作用 | 设计要点 |
| :--- | :--- | :--- |
| **胸腔反应堆** | 供能 / 过热风险 | 决定可超频程度 |
| **下肢推进** | 直接改写走位规则 | 履带免疫击退并撞飞敌人；悬浮无视积水火焰且可越障；跳跃腿无视高低差 |
| **左臂 / 右臂** | 伤害 + 伤害类型 | 伤害类型决定战利品完好度（爆炸 10% / 斩击 90% / EMP 85% 但带病毒） |
| **背部 ×4** | 货舱与散热器共享 | 贪婪的直接代价：多带货 = 少散热 = 更易红温自爆 |

- **机制心脏（背部共享槽）**：贪婪第一次有了明确的战斗代价；弃货既是断尾求生，又能在棋盘上留下一个可导电的实体掩体。

## 六、单局与局外结构

- **单局（Raid）**：待定。
- **局外**：黑市机库永久保存撤离带出的义体与蓝图，解决 Roguelike“死后归零”的大众门槛问题。
